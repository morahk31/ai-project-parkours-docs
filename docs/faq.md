# Questions fréquentes

## Pendant la balade

??? question "Ma position n'est pas reconnue, que faire ?"
    Vérifiez que la localisation est autorisée pour le site dans votre navigateur, placez-vous à l'air libre et patientez quelques secondes sans bouger avant de réessayer. Après plusieurs échecs, le bouton **Continuer sans validation GPS** vous permet de poursuivre. Détails : [Valider sa présence](balader/valider-sa-presence.md).

??? question "L'application me dit que je suis trop loin alors que je suis sur place."
    Le point de validation est parfois au centre d'une place ou devant une entrée précise : relisez la description de l'étape et avancez de quelques dizaines de mètres. Dans les rues étroites, le GPS peut aussi être imprécis : patientez puis réessayez.

??? question "Puis-je faire les étapes dans le désordre ?"
    Non. Les étapes se débloquent une par une, dans l'ordre prévu par l'auteur du parcours.

??? question "Une mauvaise réponse m'empêche-t-elle de continuer ?"
    Non. Une étape est terminée dès que le questionnaire est validé, quelles que soient les réponses. Le score ne sert qu'à déterminer le niveau de la médaille.

??? question "J'ai validé mes réponses trop vite, puis-je les corriger ?"
    Non, les réponses validées sont définitives pour cette tentative. Vous pouvez refaire le parcours plus tard pour améliorer votre médaille.

??? question "Il n'y a plus de réseau, est-ce que je perds ma progression ?"
    Non. Vos actions sont enregistrées sur l'appareil et envoyées automatiquement au retour du réseau. Voir [Sans connexion](balader/hors-ligne.md).

## Médailles et compte

??? question "Dois-je créer un compte ?"
    Non, mais sans compte votre progression et vos médailles restent sur votre appareil et dans votre navigateur. Un compte les conserve durablement et permet de reprendre un parcours sur un autre appareil.

??? question "J'ai fini un parcours sans compte, comment garder ma médaille ?"
    Créez un compte ou connectez-vous **sur le même appareil**, puis suivez [Récupérer une médaille](compte/recuperer-une-medaille.md).

??? question "Comment obtenir la médaille d'or ?"
    Répondez juste à 100 % des questions notées du parcours. Vous pouvez refaire le parcours : votre médaille ne peut que s'améliorer.

??? question "Comment prouver que ma médaille est authentique ?"
    Partagez son **code de vérification**. N'importe qui peut le saisir sur la page de vérification pour voir le parcours, le niveau et la date d'obtention.

??? question "J'ai oublié mon mot de passe."
    Sur l'écran de connexion, touchez **Mot de passe oublié ?** et suivez le lien reçu par e-mail. Voir [Créer un compte et se connecter](compte/creer-un-compte.md#mot-de-passe-oublie).

## Avis et commentaires

??? question "Pourquoi ne puis-je pas noter le parcours ?"
    Il faut avoir **commencé** le parcours pour le noter ou le commenter.

??? question "Puis-je modifier mon commentaire ?"
    Oui, pendant 24 heures après sa publication. Vous pouvez aussi le supprimer.

## Contributeurs

??? question "Pourquoi mon parcours n'apparaît-il pas dans le catalogue ?"
    Seuls les parcours **publiés** y figurent. Un parcours soumis doit d'abord être approuvé par un administrateur. Vérifiez son statut dans le studio.

??? question "Mon parcours a été refusé, que faire ?"
    Le motif du refus est affiché en haut de l'éditeur. Corrigez le parcours, puis soumettez-le à nouveau.

??? question "Pourquoi mes statistiques affichent-elles « Données insuffisantes » ?"
    Pour protéger l'anonymat des promeneurs, une valeur calculée sur moins de 5 personnes est masquée. Elle s'affichera quand le parcours aura été fait par davantage de monde.
