# Sans connexion

En ville, le réseau peut être faible : ruelles, sous-sols, zones blanches. Balad'Quest est conçu pour continuer à fonctionner en partie **sans connexion**.

## Ce qui fonctionne sans réseau

- Le contenu du parcours **déjà ouvert** : étapes consultées, descriptions, encarts *Le saviez-vous ?*, questionnaires.
- Vos réponses en cours.
- Les actions que vous faites (validation de présence, réponses, commentaire…) : elles sont **mises en attente** sur l'appareil.

## Ce qui demande le réseau

- Ouvrir un parcours **pour la première fois**.
- La confirmation définitive de vos validations et de vos réponses.
- La confirmation définitive de votre médaille.
- La publication d'une note ou d'un commentaire.

## La synchronisation

Quand une action est faite hors connexion, l'application affiche :

> Hors connexion : votre action est enregistrée sur cet appareil et sera synchronisée automatiquement dès le retour de la connexion.

Un bandeau indique le nombre d'actions en attente. Dès que le réseau revient, tout est envoyé automatiquement, dans l'ordre. Une action envoyée deux fois n'est jamais comptée deux fois.

!!! tip "Bon à savoir"
    - Les actions en attente sont conservées même si vous fermez le navigateur.
    - Ne videz pas les données du navigateur tant que des actions sont en attente.
    - Avant de partir, ouvrez le parcours avec une bonne connexion (Wi-Fi de l'hôtel, par exemple).
