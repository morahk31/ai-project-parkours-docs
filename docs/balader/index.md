# Se balader

Un parcours Balad'Quest se déroule toujours de la même façon :

1. **Choisir un parcours** dans le catalogue, ou scanner son QR code sur place.
2. **Commencer** : un écran rappelle comment la localisation est utilisée.
3. **Rejoindre chaque étape dans l'ordre** : une étape ne se débloque que lorsque la précédente est terminée.
4. **Valider sa présence** sur le lieu de l'étape, avec la localisation du téléphone.
5. **Répondre au questionnaire**, s'il y en a un. Une étape sans questionnaire est un simple *point de passage*.
6. **Recevoir sa médaille** (bronze, argent ou or) à la fin du parcours.

Vous n'avez **pas besoin de compte**. Sans compte, votre progression reste sur votre appareil ; avec un compte, elle vous suit partout. Voir [Mon compte](../compte/index.md).

## Avant de partir

- Un **smartphone** avec un navigateur récent et la **localisation activée**.
- Une **connexion internet** pour ouvrir le parcours la première fois. Ensuite, une partie du parcours fonctionne même avec un réseau faible : voir [Sans connexion](hors-ligne.md).
- De bonnes chaussures : lisez les **informations pratiques** et les **consignes de sécurité** affichées sur la fiche du parcours.
