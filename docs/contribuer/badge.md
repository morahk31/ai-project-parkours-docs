# Badge et médailles

Chaque parcours a **un badge**, obligatoire avant la soumission. Le promeneur qui termine le parcours obtient ce badge sous forme de médaille **Bronze**, **Argent** ou **Or**.

## Définir le badge

Dans la section **Badge du parcours** de l'éditeur :

- **Nom du badge** : par exemple *Explorateur du Vieux Lyon* ;
- **Description du badge** : par exemple *Décerné pour avoir terminé la balade du Vieux Lyon.*

Touchez **Enregistrer**.

## Le barème (fixe)

Le barème est le même pour tous les parcours de la plateforme et ne se configure pas :

| Médaille | Score aux questions notées |
| --- | --- |
| **Or** | 100 % |
| **Argent** | 66 % ou plus |
| **Bronze** | moins de 66 % |

- Seules les questions *Choix unique*, *Choix multiple* et *Vrai / Faux* comptent.
- Un parcours **sans aucune question notée** donne toujours la médaille **Or**.
- Le temps de parcours n'entre pas en compte.

!!! tip "Calibrer la difficulté"
    Avec très peu de questions, une seule erreur fait chuter le score : une erreur sur 3 questions donne 67 % (Argent), deux erreurs donnent 33 % (Bronze). Avec 8 à 12 questions sur l'ensemble du parcours, les niveaux de médaille sont plus nuancés.
