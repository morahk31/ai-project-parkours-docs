# QR code

Chaque parcours publié dispose d'**un QR code actif**. Scanné avec un téléphone, il ouvre directement la fiche du parcours. Placez-le sur une affiche, un dépliant, un panneau au point de départ…

## Obtenir le QR code

Le QR code est **généré automatiquement lors de la première publication** du parcours. Il apparaît ensuite dans la section **QR code** de l'éditeur, avec le lien qu'il contient.

- **Télécharger (SVG)** : une image vectorielle, imprimable à n'importe quelle taille sans perte de qualité.

## Remplacer le QR code

Si un QR code a été dégradé, détourné ou diffusé par erreur, touchez **Remplacer le QR code**. Vous pouvez donner un **libellé** au nouveau code (par exemple *Affiche office de tourisme*).

!!! warning "L'ancien QR code cesse de fonctionner"
    Un promeneur qui scanne l'ancien QR code voit la page *QR code périmé*, avec un lien vers le parcours. Pensez à remplacer les supports imprimés.

Le remplacement ne change **rien d'autre** : l'adresse du parcours, son historique, ses statistiques, ses médailles, ses notes et ses commentaires sont conservés.
