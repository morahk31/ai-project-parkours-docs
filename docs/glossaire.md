# Glossaire

**Badge**
:   Récompense propre à un parcours, obtenue en le terminant, sous forme de médaille Bronze, Argent ou Or.

**Code de vérification**
:   Code unique imprimé sur une médaille, qui permet à quiconque de vérifier son authenticité.

**Contributeur**
:   Utilisateur autorisé à créer et gérer ses propres parcours dans le studio.

**Étape standard**
:   Étape avec un questionnaire. Terminée quand la présence et le questionnaire sont validés.

**Médaille**
:   Niveau obtenu pour le badge d'un parcours : Or (100 % de bonnes réponses), Argent (66 % ou plus), Bronze (en dessous).

**Membre**
:   Utilisateur avec un compte : progression, médailles et historique conservés.

**Parcours**
:   Itinéraire à pied dans une ville, composé d'étapes à suivre dans l'ordre.

**Point de passage**
:   Étape sans questionnaire, terminée dès que la présence est validée.

**QR code**
:   Code à scanner qui ouvre directement la fiche d'un parcours. Un seul QR code est actif par parcours.

**Studio contributeur**
:   Espace où les contributeurs créent leurs parcours, consultent leurs statistiques et modèrent les commentaires.

**Tentative**
:   Une réalisation d'un parcours par une personne, du début à la fin (ou à l'abandon).

**Validation assistée**
:   Possibilité de continuer sans validation GPS après plusieurs échecs de localisation.

**Validation de présence**
:   Lecture ponctuelle de la position du téléphone pour vérifier qu'on se trouve dans la zone d'une étape.

**Visiteur**
:   Utilisateur sans compte. Sa progression reste sur l'appareil utilisé.

**Zone de validation**
:   Cercle autour du point d'une étape (rayon de 20 à 200 m) dans lequel il faut se trouver pour valider sa présence.
