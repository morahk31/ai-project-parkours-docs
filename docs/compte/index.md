# Mon compte

Un compte Balad'Quest est **gratuit** et **facultatif**. Il apporte :

- une progression **sauvegardée** : reprenez un parcours plus tard, sur n'importe quel appareil ;
- vos **médailles conservées** dans votre espace, sans risque de les perdre en changeant de téléphone ;
- un **historique** de vos balades, visible de vous seul.

Pour créer un compte, il suffit d'une adresse e-mail, d'un nom affiché et d'un mot de passe.

## Naviguer dans l'application

Sur smartphone, une barre en bas de l'écran donne accès à :

- **Parcours** : le catalogue ;
- **Mes parcours** : vos parcours en cours, terminés et vos médailles ;
- **Compte** : profil, mot de passe, déconnexion.

Les contributeurs y trouvent aussi l'accès au **Studio contributeur** et à la **Modération**.
